# Synthetic normalized GIF corpus

Generated by `firmware/tools/generate_gif_fixtures.py` using the Companion's
`td_host::gif_normalize::normalize_gif`, with the proposed Device limits.
All pixels are synthetic xorshift noise; no user images are included.

Cases 00–23 use 255 colors at 128 square pixels with fitted widths 128–105.
Cases 24–31 use three frames and 2, 3, 4, 5, 8, 16, 32 and 64 colors.
The seeds and palette match the normalizer's dictionary/end-code regression
fixtures. Contain and cover alternate. `manifest.tsv` records canvas dimensions
and delays. The host decoder test checks every frame in reverse order against
Pillow's composed pixels, as RGB565 followed by alpha.
